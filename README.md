# Chrome Extension - Site Blocker

![Extension Icon](image.png)

A Chrome extension to help you stay focused by blocking distracting sites.

## Features

- **YouTube** - Hides recommendations, sidebar, and distracting elements
- **Reddit** - Hides sidebars
- **Instagram** - Fully blocked

## Installation

1. Go to `chrome://extensions`
2. Enable "Developer mode"
3. Click "Load unpacked"
4. Select this folder
